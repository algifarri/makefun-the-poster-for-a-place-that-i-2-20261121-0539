A deterministic, pure-stdlib Python program that procedurally renders a vintage travel poster for SOLMARA — an island that does not exist, where a great stone arch carries a lighthouse and the sun sets through the arch while a crescent moon is already up. Layered sunset sky with ordered dithering, a banded retro sun, shining sea with a glitter path, palm silhouettes, and the place's name set into the picture in large deco stroke lettering. It writes one PNG to /output/entry.png (90,646 bytes, 1024×1024).

## Run it

```sh
python3 main.py
```
